# COCO 2017 圖片播放器

使用 Python 3 標準函式庫，依 COCO 的 `annotations/instances_val2017.json` 分類。圖片可同時屬於多個物件類別，同一張圖片在同一類別只會出現一次。沒有物件標註的圖片列入總數，但不進入類別播放清單。

```bash
python3 coco_player.py --list
python3 coco_player.py --host 0.0.0.0
```

第一行列出所有類別與各類的圖片張數。第二行啟動播放器，在同一區域網路的瀏覽器開啟 `http://192.168.8.235:8765/`。如果在樹莓派本機瀏覽，可執行 `python3 coco_player.py` 並開啟 `http://127.0.0.1:8765/`。

按「開始播放」後，播放器按 COCO 類別 ID 順序播放。每類先顯示名稱 2.5 秒，再按檔名順序顯示圖片，每張 2 秒。可暫停、手動前進，或從下拉選單切換類別。

「播放模式」提供三種選擇：

- 「依序播放一次」為預設，從目前分類播到最後一類後停止。
- 「單一分類循環」會在目前分類播完後，重新顯示該分類名稱並播放第一張圖片。
- 「全部分類循環」從目前分類繼續往後播放，最後一類播完後接回第一類，持續循環。

可在播放或暫停時切換模式，於下一次分類結束時套用。播放完畢後切換模式，會回到待播放畫面，需按「開始播放」。循環播放會先顯示分類名稱，並沿用圖片及分類名稱的停留時間。全部分類循環依標註播放，同一張圖片可能出現在多個分類，48 張無物件標註的圖片不列入播放。

瀏覽器上方可調整播放區高度（視窗高度的 20%～90%）、每張圖片停留時間和類別名稱停留時間（各 0.5～60 秒）。圖片維持原始比例完整顯示，播放時會列出原始像素與實際顯示尺寸。播放中的對應時間設定變更後，從變更當下重新計時。設定在重新整理後恢復預設。

按「播放區全螢幕」可讓圖片與類別名稱使用整個螢幕，圖片維持比例完整顯示。可先開始播放再進入全螢幕，按 Esc 或右上角的「退出全螢幕」返回。全螢幕時圖片高度使用整個畫面，退出後恢復高度滑桿的設定。

更新播放器檔案後，請在執行程式的終端機按 Ctrl+C，再重新執行並重新整理瀏覽器。

程式預設在專案目錄找資料，可用 `--data-dir` 指定其他位置。若所需圖片或標註尚未解壓，程式會使用現有 ZIP，或在缺少 ZIP 時下載。若官方下載網域連線失敗，會嘗試同一個 S3 儲存桶的 HTTPS 網址。
